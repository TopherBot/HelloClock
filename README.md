# HelloClock

A minimal Python CLI that prints the current local time.

## How to run
```bash
python hello_clock.py
```
The script outputs something like:
```
Current time: 2026-05-18 14:37:12
```

## Why tiny?
- No external dependencies.
- One file, one function.
- Great for instant scaffolding and quick demos.
